# 다층·다경간 라멘골조 설명서

## 1. 확장 범위

층수와 경간수에 따라 절점, 부재, 자유도, 경계조건을 자동 생성합니다. 기존 1층 1경간 요소 함수를 재사용하며 OpenSees는 필요하지 않습니다. 2층 2경간과 3층 3경간의 표와 그림을 생성했습니다. 5층 5경간 및 비정형 치수 모델도 수치 검증했습니다.

기존 README.md의 Timoshenko 요소·가상일·전단면적 가정은 그대로 적용됩니다. 바뀐 것은 골조 생성, 구속 자유도 선정, 전체 행렬 크기 및 다부재 출력입니다. 기존 `frame_analysis.py`는 계속 1층 1경간 예제를 실행합니다.

## 2. 변위 조건 — 반드시 확인할 내용

**최상층의 모든 절점에 같은 수평변위 Δ를 지정**합니다. 모든 기초 절점은 완전고정입니다. 중간층의 수평변위, 모든 상부 절점의 수직변위와 회전은 해석 결과입니다.

- 모든 층을 같은 변위로 밀거나, 층별 선형 변위 형상을 미리 지정한 모델이 아닙니다.
- 중간층에 강체 다이어프램을 가정하지 않습니다. 같은 층의 절점 수평변위도 미세하게 다를 수 있습니다.
- 결과의 전체 기여도는 **최상층 지정 변위에 대한 기여도**입니다.
- 층별 기여량은 그 층의 기둥과 상단 보를 묶은 값이며 층간변위 자체가 아닙니다.
- 실제 층간변위는 각 수직 기둥선의 상하 절점 ux 차이로 따로 출력합니다.

최상층 구동력 합을 Q라고 하면 실제 반력 패턴/Q를 합력 1 N인 가상하중으로 사용합니다. 최상층 각 실제 변위가 Δ이므로 외부 가상일은 1 N×Δ입니다. 따라서 부재 수와 관계없이 다음 관계를 유지합니다.

$$\Delta=\sum_e(C_{N,e}+C_{V,e}+C_{M,e}),\qquad C_e=2U_e/Q$$

현재는 선형탄성·소변형·등단면·강접합이며 부재 중간 하중, 중력, 소성, P–Δ를 포함하지 않습니다. 전단면적 기본값 As/A=5/6은 예제 가정입니다.

## 3. 파일 구성과 실행

다음 세 파일을 같은 폴더에 두어야 합니다.

| 파일 | 역할 |
|---|---|
| frame_analysis.py | Timoshenko 요소·좌표변환·선형계 해법·가상일 적분 |
| multi_frame.py | 다층·다경간 생성 및 해석, 명령행 실행 |
| multi_frame_reports.py | CSV·Markdown·표 그림·골조 그림 저장 |
| test_multi_frame.py | 수치 검증 실행 |

```bash
python -m pip install numpy matplotlib
python multi_frame.py --examples
python multi_frame.py --stories 2 --bays 2
python multi_frame.py --stories 3 --bays 3
python multi_frame.py --stories 3 --bays 2 --span 5 --height 3.5 --delta-mm 8
python test_multi_frame.py
```

`--examples`는 1층 1경간, 2층 2경간, 3층 3경간을 모두 저장합니다. `--span`은 한 경간 길이, `--height`는 한 층 높이입니다. 결과 경로는 `results/2F_2B`, `results/3F_3B` 같은 형식입니다. 같은 층수·경간수로 재실행하면 해당 폴더의 결과를 갱신합니다.

서로 다른 층고·경간은 Python 입력으로 지정합니다.

```python
from pathlib import Path
from multi_frame import Parameters, analyze, export

p = Parameters(
    stories=3, bays=3,
    bay_widths=(4.0, 5.0, 6.0),
    story_heights=(3.5, 3.0, 2.8),
    delta=0.01,
    beam_I=8e-5, column_I=8e-5,
    beam_shear_factor=5/6, column_shear_factor=5/6,
)
result = analyze(p)
export(result, Path('results/custom'))
```

bay_widths 또는 story_heights가 주어지면 각각 span 또는 height보다 우선합니다. A,I는 기둥군·보군별로 공통입니다. `left_I_factor`, `right_I_factor`는 모든 층의 최외곽 좌·우 기둥에 적용합니다. 임의 부재별 단면을 지정하는 기능까지 구현한 것은 아닙니다.

## 4. 단계별 코드 구조

1. **입력 검증:** 층수·경간수·치수·단면·재료 입력을 확인합니다.
2. **골조 생성:** 아래층부터 각 층의 절점을 왼쪽에서 오른쪽으로 생성합니다. 기둥과 보를 연결합니다.
3. **실제 상태:** 최상층 지정 변위 문제를 풉니다. 모든 기초는 고정합니다.
4. **가상 상태:** 실제 구동 반력 패턴을 정규화한 하중으로 별도 해석합니다.
5. **부재 적분:** 축·전단·휨 가상일과 에너지를 각각 적분합니다.
6. **항등식·평형 검증:** 전체 가상일, 에너지, 자유 자유도 잔차, 힘과 모멘트 평형을 검사합니다.
7. **보고서:** 부재별·층별·절점별 표와 그림을 저장합니다.
8. **명령행 실행:** 선택한 층수·경간수 또는 예제 세 개를 실행합니다.

각 절점은 ux,uy,θ의 3개 자유도를 가집니다. n층 b경간의 절점 수는 (n+1)(b+1), 부재 수는 n(2b+1)입니다. 전체 행렬 크기는 3(n+1)(b+1)입니다. 제약조건 적용 전 자유도 수이며 고정 자유도도 포함합니다.

## 6. portion % 읽는 방법

**차트 옆 숫자는 전체 지정 변위 기준입니다.** 예를 들어 축 0.1%, 전단 0.3%, 휨 9.6%라면 그 부재의 전체 참여율은 10%입니다.

$$p_{N,e}=100C_{N,e}/\Delta$$

**부재 내부 비율**은 해당 부재의 총 기여량을 분모로 하므로 세 성분의 합이 100%입니다.

$$r_{N,e}=100C_{N,e}/C_e$$

component_portions.csv와 report.md는 두 비율을 모두 제공합니다. 기여량이 사실상 0인 부재는 내부 비율을 정의할 수 없으므로 NaN으로 기록합니다. 차트에서 0.0000으로 보이는 값은 반올림 결과일 수 있습니다. 원시 CSV는 계산 정밀도를 유지합니다. 극미소 음수에 의한 -0 표시는 표·그림에서만 0으로 정리합니다.

## 8. 실행 결과 및 검증

아래는 경간마다 6 m, 층마다 3 m, 최상층 변위 10 mm 및 기존 단면값의 결과입니다.

| 모델 | 절점 | 부재 | 전체 자유도 | 반력 합 (kN) | 최대 참여 부재 | 각각의 참여율 |
|---|---:|---:|---:|---:|---|---:|
| 1층 1경간 | 4 | 3 | 12 | 80.363989 | C1, C2 | 34.0853% |
| 2층 2경간 | 9 | 10 | 27 | 40.335266 | G1, G2 | 16.2495% |
| 3층 3경간 | 16 | 21 | 48 | 32.688586 | G4, G6 | 9.0754% |

큰 골조에서도 반드시 기둥이 가장 active한 것은 아닙니다. 예제에서는 중간층 보의 휨변형이 최상층 변위에 크게 기여합니다. 이는 이 하중·변위 조건과 단면에 대한 결과이며 부재 위험도 순위가 아닙니다.

검증 결과는 results/multi_verification.json에 저장됩니다. 1×1, 2×2, 3×3, 2×3, 3×2, 5×5 및 서로 다른 경간·층고와 음의 변위를 적용한 비대칭 사례가 통과했습니다.

- 기존 1층 1경간 결과와 일치
- 외팔보 끝단 변위·회전의 독립 이론해와 일치
- 가상일·에너지·힘·모멘트 평형
- 대칭 부재의 동일 참여율 및 변위 배율 법칙
- 각 부재를 두 요소로 분할해도 절점 응답 및 원래 부재별 기여량 유지
- 보 I 변화에 대한 가상 해석 민감도와 중앙차분 일치
- 잘못된 층수·치수 배열 길이·0 변위 입력 거부

2×2, 3×3의 가상일 합산 오차는 각각 약 1.6×10⁻¹⁵ m, 1.8×10⁻¹⁵ m입니다. 더 큰 모델에도 같은 수식을 적용할 수 있으나 현재는 NumPy의 밀집행렬 풀이이므로 대규모 모델은 희소행렬로 바꾸는 것이 적합합니다. 범용 구조설계 프로그램의 모든 입력·안정성 진단을 제공하는 코드는 아닙니다.
